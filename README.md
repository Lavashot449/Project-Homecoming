# Borderlands Showcase

Static GitHub Pages skeleton for the four custom Vault Hunters.

## Included
- Home/roster page
- Rook, Yausuan, Veyra, and Karn page shells
- Shared responsive styling
- Shared dynamic skill-tree calculator engine
- JSON data files per character
- Dedicated portrait/icon asset folders
- Locked tiers, rank limits, point spending, right-click point removal, and reset-build behavior
